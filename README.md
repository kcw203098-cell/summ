# YT 요약노트 (휴대폰용 PWA)

## 1. 올리기 (GitHub Pages, 무료, 한 번만)
1. github.com 에 로그인하고 새 저장소(public)를 만듭니다. 예: ytnote
2. Add file → Upload files 로 이 폴더의 파일 8개를 모두 올립니다.
3. Settings → Pages → Branch: main / (root) → Save
4. 1~2분 뒤 https://<아이디>.github.io/ytnote/ 가 열립니다.

## 2. 설치
- Android(Chrome): 주소를 열고 메뉴 ⋮ → "앱 설치"(또는 홈 화면에 추가)
- iPhone(Safari): 공유 → 홈 화면에 추가

## 3. 쓰기
- Android: YouTube 앱 → 공유 → "YT 요약노트" → 자동 요약
- 주소 복사 → 앱으로 돌아오기 → 자동 요약 (Android Chrome, 클립보드 권한 허용 시)
- iPhone: 주소 복사 → 앱 열기 → "붙여넣기"
- 결과: MD 복사(옵시디언) / 텍스트(메모장) / 공유(삼성노트·Keep 등) / 옵시디언(바로 새 노트 생성)

API 키는 설정(⚙)에 넣습니다. 키는 그 휴대폰 브라우저에만 저장되고 저장소에는 올라가지 않습니다.
